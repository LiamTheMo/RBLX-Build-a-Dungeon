# Build a Dungeon

Build a Dungeon is a relaxed Roblox dungeon-management game. Each player owns a plot and arranges rooms, defenders and traps into a single route. NPC adventurers arrive, fight through the rooms, and either fall or escape. A defeated adventurer pays coins (banked, or into the vault with a treasure room) and may drop boxes and blueprints for new rooms. Placing a treasure room is optional: it brings visitors more often and raises rewards, but adventurers who reach it steal from the unbanked vault.
