# Build a Dungeon

A relaxed Roblox dungeon-management game. Arrange miniature rooms, monsters and traps into a route, watch NPC adventurers try to get through, and reinvest the rewards. Placing a treasure room is optional: it draws more visitors and pays more, but adventurers who reach it steal from the vault.
